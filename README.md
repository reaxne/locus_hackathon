# Вектор ↗

Стартовый React-проект по кейсу № 2 «Персональный маршрут поступления» LOCUS Startup Hackathon 2026. Сервис для учеников 9–11 классов и выпускников, планирующих поступление на бакалавриат. Интерфейс на русском, адаптирован к компьютеру и телефону.

## Что работает

- Обзор с демо-профилем и понятным входом в собственный маршрут.
- Анкета из трёх шагов: имя, класс, направление, средний балл, IELTS, страны, бюджет и год поступления.
- Диагностика: цель, сильные стороны и ограничения.
- Подбор девяти учебных программ с объяснением каждого из пяти критериев. На обзоре — три лучших варианта.
- Поиск и фильтр по стране, сравнение двух или трёх программ.
- Выбор программы и персональный план: требования, экзамен, документы, активности, заявка; при необходимости — финансирование и улучшение оценок.
- Ближайший шаг, отметки выполнения, процент прогресса.
- Сохранение профиля, сравнения, цели и прогресса в localStorage. Восстановление при перезагрузке; безопасный возврат к демо при повреждённых данных.
- После сохранения изменённого профиля пересчитывается подбор и начинается новый план. Выбранные для сравнения программы сохраняются.

## Быстрый запуск

Нужен Node.js **22.12+** (рекомендуется Node.js 22 LTS) и npm.

```sh
npm ci
npm run dev
```

Адрес: http://localhost:5173. Ключи API и база данных не нужны.

Production-сборка:

```sh
npm run build
npm start
```

Адрес по умолчанию: http://localhost:3000. Сервер слушает `0.0.0.0` и порт из `PORT`, возвращает `200` и JSON на `GET /health`. Статика собирается в `dist`. Неизвестные маршруты с запросом HTML возвращают оболочку приложения, отсутствующие файлы — `404`.

## Развёртывание на Railway

В корне уже есть многоэтапный **Dockerfile**. Railway обнаруживает его автоматически; приложение не зависит от Vite dev server в production.

1. Добавьте этот проект в свой GitHub-репозиторий, включая `package-lock.json`.
2. В Railway создайте проект → **Deploy from GitHub repo**, выберите репозиторий. Корень сервиса — папка с `Dockerfile`.
3. Сборка и запуск заданы в Dockerfile. Дополнительные Build Command и Start Command не нужны.
4. В настройках сервиса установите **Healthcheck Path**: `/health`.
5. В **Networking → Public Networking** нажмите **Generate Domain**. Если Railway запросит порт, укажите порт из `PORT` (в образе по умолчанию `3000`). Сервер использует назначенный Railway `PORT` автоматически.

Нет обязательных переменных окружения, базы данных или постоянного тома. `NODE_ENV=production` задан в образе. Контейнер запускается от непривилегированного пользователя `node` и завершает HTTP-сервер по SIGTERM.

Если позднее подключите AI/API, секретные ключи храните в серверных переменных Railway. Переменные `VITE_*` попадают в клиентскую сборку и не подходят для секретов.

Документация: [React на Railway](https://docs.railway.com/guides/react), [Dockerfiles](https://docs.railway.com/builds/dockerfiles), [Healthchecks](https://docs.railway.com/deployments/healthchecks).

Деплой в аккаунт Railway в рамках создания проекта не выполнялся. Docker-образ требует отдельной сборки на Railway или машине с Docker.

## Архитектура

```text
src/
  App.tsx          Экраны, навигация, анкета, модальные окна, состояние
  model.ts         Типы, учебный каталог, ранжирование, roadmap, валидация
  model.test.ts    Проверки персонализации и восстановления состояния
  main.tsx         Вход React и локальные шрифты
  styles.css       Адаптивная дизайн-система
tests/
  journey.spec.ts  Полный пользовательский путь на desktop и mobile
server.mjs        Production HTTP-сервер Express
Dockerfile        Сборка React + минимальный production-контейнер
```

Навигация использует адреса `#overview`, `#profile`, `#programs`, `#compare`, `#roadmap`; выбранный экран сохраняется при обновлении. Состояние хранится под ключом `vector-admission-v1`, формат версионирован. При блокировке localStorage интерфейс объясняет, что сохранение недоступно, и продолжает работать в памяти.

## Логика рекомендаций и AI

Эта версия использует **правила, а не внешнюю LLM**. Баллы сортировки: направление — 40, страна — 25, стоимость в пределах бюджета — 30, IELTS — 8, средний балл — 7. При равном результате первым показывается более доступный вариант. Пользователь видит число совпавших критериев и причины, а не внутренний балл и не «вероятность поступления».

Каталог не скрывает варианты вне ограничений: они занимают более низкие позиции, а в подробностях перечислены расхождения. Это позволяет осмысленно сравнить альтернативы при малом бюджете или недостаточной подготовке.

План зависит от выбранной программы, бюджета, среднего балла, IELTS, направления, страны и года. Сроки — относительные ориентиры для подготовки; официальные даты поступления не выдумываются.

Внешние AI/API в проект не подключены. Для следующей итерации можно сохранить детерминированную проверку ограничений и добавить серверный AI для объяснения рекомендаций на основе подтверждённых данных вузов.

## Данные, источники и готовые компоненты

- Основа продуктового сценария: предоставленный PDF `LOCUS_Hackathon_2026_Case_2_Admission_Journey.pdf`. Организационные указания о сабмите, публикациях и коммуникациях не выполнялись.
- Все университеты, программы, цены и требования в каталоге **вымышлены для демонстрации**. Они не являются сведениями о существующих организациях. Соответствующее пояснение есть в интерфейсе. Перед реальным использованием каталог нужно заменить проверенными данными со ссылками на первоисточники и датами проверки.
- React, React DOM, TypeScript, Vite — приложение и сборка.
- Express — раздача production-сборки, `PORT` и проверка работоспособности.
- Lucide React — готовые иконки. Полный UI-kit не использован; компоненты и стили созданы для проекта.
- Manrope Variable через Fontsource — локально размещённый шрифт, включая кириллицу; внешних запросов к Google Fonts нет.
- Vitest и Playwright — проверки логики и пользовательского пути; Prettier — форматирование.
- Точные версии зависимостей зафиксированы в `package-lock.json`.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

Для e2e нужен установленный Google Chrome. Playwright использует `channel: 'chrome'`; при необходимости установите Chrome командой `npx playwright install chrome`. Мобильный проект эмулирует размер экрана и touch в Chromium, а не запускает настоящий iOS Safari. E2E автоматически запускают production-сервер на порту 3000, если он не запущен. Перед ними соберите приложение.

Ручной сценарий:

1. Нажмите «Построить мой маршрут» и заполните три шага.
2. Откройте подборку, изучите причины совпадения и ограничения.
3. Добавьте две программы через `+`, откройте сравнение и выберите цель.
4. Отметьте первую задачу выполненной и перезагрузите страницу — прогресс должен сохраниться.
5. Измените бюджет, страну, направление или IELTS. Убедитесь, что подбор или задачи меняются, а прогресс нового плана начинается с нуля.
6. Проверьте пустой результат поиска, незаполненную страну, закрытие модального окна клавишей Escape и экран шириной 390 px.

## Ограничения и развитие

- Нет авторизации, общей базы данных и синхронизации между устройствами. Очистка данных браузера удалит профиль и прогресс.
- Есть только англоязычный бакалавриат, три направления, три страны и IELTS. Не учитываются гражданство, визовые ограничения, признание аттестата и полный набор экзаменов.
- Бюджет относится только к обучению; проживание, перелёты, страховка и виза в него не включены.
- Нет гарантий поступления, отправки заявок, реальных дедлайнов, уведомлений и загрузки документов.
- Для следующего этапа: реальные данные и источники, API и база PostgreSQL, затем AI-объяснения с проверкой фактов.
